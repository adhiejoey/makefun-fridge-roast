Entry for the make.fun bounty **Fridge Roast: One Line, Biggest Laugh** (`u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb`, $5 prize).

`main.ts` (Node.js standard library only, no network) writes a single one-line roast of a smart fridge to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The entry:

> My smart fridge lost Wi-Fi and refused to make ice, so now a $3,000 box just stands there glowing, cold, useless, and somehow still smug.

Run it with:

```sh
node main.ts
```
